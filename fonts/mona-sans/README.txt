Complete Mona Sans fonts matching the Universe 2026 template's static faces.

MonaSans-*.ttf: Mona Sans, version 2.022
MonaSansDisplay-*.ttf: Mona Sans Display, version 2.022
MonaSansMono-*.ttf: Mona Sans Mono, version 0.005

Source (original, unmodified TTF files):
https://github.com/github/mona-sans/tree/de18b7a15d837ea1f873ba2b000b9a44ddba9ca8/fonts/static/ttf

The template embeds subsets with only 130-131 encoded characters, excluding
the Latin macrons used in this talk. These complete files restore the font's
Unicode coverage and mark positioning. Every shared character's outline and
horizontal metrics were checked against the corresponding embedded font.

Only one version of each family is bundled. The template's older Mona Sans
1.001 variable font is omitted to avoid ambiguous regular/italic selection.
